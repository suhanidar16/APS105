# APS105 – Computer Fundamentals | C Programming

**Lab 1 – Fundamental Programming & Arithmetic**

Developed C programs for numerical calculations, unit conversions, and formatted output. Applied arithmetic operators, data types, and input/output operations to solve practical problems.

**Lab 2 – Mathematical Computing & Algorithms**

Implemented mathematical algorithms for escape velocity, electrostatic force calculations, and numerical decoding. Applied mathematical libraries, arithmetic operations, and computational problem-solving techniques.

**Lab 3 – Conditional Logic & Iterative Algorithms**

Developed programs for substance identification, projectile calculations, and ATM cash distribution. Implemented conditional branching, iterative loops, and input validation.

**Lab 4 – Numerical Algorithms & Functional Decomposition**

Implemented iterative numerical approximation and number-classification algorithms. Applied modular function design, loop control, and mathematical reasoning to solve computational problems.

**Lab 5 – Cellular Automata Simulation**

Developed a one-dimensional cellular automaton simulator using binary-encoded transition rules. Implemented array manipulation, neighborhood-based state updates, and boundary-condition handling.

**Lab 6 – Connect Four Game Engine**

Built a two-player Connect Four game in C using multidimensional arrays and modular functions. Implemented move validation, board-state updates, and horizontal, vertical, and diagonal win detection.

**Lab 7 – Reversi Game Logic & Move Validation**

Developed a Reversi game engine with dynamic board configurations and eight-directional move validation. Implemented multidimensional array traversal, legal-move detection, and automated tile-flipping logic.

**Lab 8 – Reversi AI & Strategic Decision-Making**

Extended the Reversi engine with computer-controlled gameplay and algorithmic move selection. Developed and evaluated move-scoring strategies to improve decision-making against human opponents.

**Lab 9 – Priority Queue & Linked List Management**

Developed a hospital emergency-room simulation using dynamically allocated singly linked lists. Implemented priority-based insertion, node deletion, queue traversal, and memory management.
